# 业务使用手册

本文面向日常业务用户，说明如何完成项目立项、审核、资料归档、任务协作、付款、搜索、导入导出、归档恢复和个人设置。

## 1. 角色与入口

| 角色 | 主要能力 |
| --- | --- |
| admin | 用户、部门、归档、导入导出、转交、审计、API Key、Webhook、系统兜底处理 |
| dept_manager | 主项目审核、子项目审核、结项、部门视角数据查看 |
| finance_manager | 付款登记、付款报表、财务仪表盘 |
| proj_leader | 子项目创建、环节推进、任务分配、资料上传、自助转交、撤销申请 |
| proj_member | 查看参与项目、执行任务、上传资料、查看通知 |

登录后左侧导航会按权限显示入口。看不到某个菜单时，先确认自己的角色和项目关系。

## 2. 登录、语言和时区

1. 打开系统地址。
2. 使用用户名/密码登录，或点击企业账号入口使用 SSO。
3. 首次登录或管理员重置密码后，根据提示修改密码。
4. 右上角语言切换可在中文和 English 之间切换，系统默认中文。
5. 进入“我的”可维护邮箱、通知偏好、企业账号绑定和时区。

时区说明：

- 系统保存 UTC 时间，页面按当前用户时区显示。
- 用户默认时区为 `Asia/Shanghai`。
- 海外用户应在个人资料中设置正确 IANA 时区，例如 `America/New_York`。
- 每日摘要和任务提醒会按用户本地 09:00 触发。

## 3. 工作台与驾驶舱

工作台展示与当前用户相关的任务、项目和通知。驾驶舱按角色展示不同数据：

- admin：全系统项目、用户、超预算、错误率。
- dept_manager：项目状态分布、部门项目数、超预算项目。
- finance_manager：付款总额、预算使用、付款排行。
- proj_leader：负责子项目、待推进环节、到期任务。
- proj_member：我的待办、参与项目动态。

仪表盘数据有短时间缓存，刷新后仍未变化时可稍等缓存过期。

## 4. 主项目流程

主项目通常由 dept_manager 创建和审核。

1. 进入“项目”。
2. 新建主项目，填写项目名称、部门、预算、预计完成日期和备注。
3. 提交审核。
4. 审核人查看资料后通过或退回。
5. 通过后可创建子项目。
6. 所有子项目完成后，dept_manager 可结项主项目。

注意：

- 创建人不能审核自己创建的主项目。
- 退回后可修改并重新提交。
- 结项时间会用于后续归档候选判断。

## 5. 子项目与环节推进

1. proj_leader 创建子项目，选择主项目、部门、预算、计划完成日期。
2. 提交审核。
3. 审核通过后，系统生成固定环节。
4. 负责人在环节页面上传必传文档、维护验收步骤、分配任务。
5. 满足必传文档和验收要求后推进下一环节。

若子项目超过预算，审核或付款时可能需要二次确认并填写原因。

## 6. 文档管理

文档支持上传、版本、预览、下载和安全扫描。

- PDF 使用内置预览。
- Word、Excel、PowerPoint 会转换成 PDF 预览。
- 新上传文件先显示“扫描中”。
- 通过后显示“已通过”。
- 风险文件显示“已隔离”，不可预览和下载。
- 同一文档类型可上传新版本，历史版本可查看。

上传失败常见原因：

- 文件超过大小限制。
- 文件类型不允许。
- 压缩包内包含风险路径或可执行文件。
- ClamAV 扫描失败，需要管理员查看 worker 日志。

## 7. 全文搜索

进入“搜索”可检索文档。

使用建议：

- 输入至少一个有效关键词。
- 文档上传后需要等待后台抽取文本和写入 PostgreSQL FTS。
- 已隔离、已删除或未通过扫描的文档不会进入结果。
- 搜索结果会展示文档、项目、环节和命中摘要。

如果刚上传的文档搜不到，先确认文档扫描状态为“已通过”，再稍后重试。

## 8. 任务协作

项目负责人可创建任务并分配执行人。执行人可在“任务”或工作台查看。

任务状态：

- 未开始。
- 进行中。
- 已逾期。
- 已完成。

移动端适合查看任务和快速完成；审核、付款和环节推进建议在 PC 端完成。

## 9. 付款与预算

finance_manager 可在子项目下登记付款。

系统会：

- 维护子项目已付款金额。
- 超预算时要求确认。
- 支持正常付款和红冲。
- 生成付款通知。
- 支持付款流水和财务报表。

录入错误时不要直接删除数据库记录，应使用业务页面的红冲或更正流程。

## 10. 通知

通知中心展示站内通知。个人设置可调整：

- 通知范围：全部、仅与我直接相关、自定义。
- 发送方式：实时或每日摘要。
- 通道：站内、邮件、企业微信、钉钉。

每日摘要会合并前一天通知，并按用户本地 09:00 发送。外部通道需要运维提前配置。

## 11. 撤销申请

proj_leader 可对已完成环节发起撤销申请。

1. 进入撤销申请。
2. 选择已完成环节。
3. 填写撤销原因。
4. 提交审核。
5. 审核通过后，系统回滚后续环节并处理相关文档。

撤销会写审计日志，原因应描述清楚。

## 12. 负责人转交

支持两类转交：

- 自助转交：proj_leader 发起，将自己负责的进行中子项目转给候选负责人。
- 管理员兜底转交：admin 处理离职、长期未响应等场景。

自助转交流程：

1. 选择需要转交的子项目。
2. 选择候选负责人。
3. 填写转交原因。
4. 候选人确认。
5. 审核通过后生效。

## 13. 归档与恢复

归档由 admin 在“归档”页面操作，普通业务用户通常只需要了解：

- 已结项且满足时间阈值的主项目会成为归档候选。
- 归档会把主项目及相关子数据迁移到 `archive_*` 表。
- 归档和恢复都有审计记录。
- 恢复前系统会检查项目编号等唯一键冲突。

归档后，主业务列表会更轻；需要恢复历史项目时联系管理员。

## 14. 批量导入

admin 可在“导入”页面下载 Excel 模板并导入历史项目。

导入规则：

- 成功行会落库。
- 失败行不会阻塞成功行。
- 结果会展示成功数、失败数、逐行错误和导入批次号。
- 1000 行本地目标为 60 秒内完成。

导入前建议先用 5-10 行样本验证字段和部门编码。

## 15. 数据库全量导出

admin 可在“导出”页面发起全库导出任务。

导出包包含：

- CSV/Excel 数据文件。
- manifest。
- 外键引用说明。
- 操作者和生成时间等审计信息。

大导出会进入后台任务。完成后可下载，下载行为会写审计日志。

## 16. 报表导出

报表入口支持：

- 项目清单。
- 付款流水。
- 部门项目汇总。
- 月度统计。

大报表异步生成，文件默认保留 7 天。

## 17. API Key 和 Webhook

本节面向 admin 和外部系统对接人员。

API Key：

1. 进入“API Key 管理”。
2. 创建 key，选择项目、付款、文档只读权限。
3. 创建后立即保存 token，页面以后只展示前缀。
4. 外部系统通过 `X-API-Key: <token>` 调用 `/api/external/v1/*`。

Webhook：

1. 进入“Webhook 管理”。
2. 配置 URL、secret、事件类型。
3. 接收方校验 `X-Signature`。
4. 失败投递会重试，最终进入死信队列，可由 admin 重放。

## 18. 常见问题

### 看不到项目

确认自己是否是管理员、部门负责人、项目负责人或项目成员。普通成员只能看自己参与的项目。

### 时间显示不符合本地时间

到“我的”页面检查时区设置。时区必须是有效 IANA 名称。

### 通知没有收到

检查个人通知偏好，确认是否选择每日摘要，或是否关闭了该通知场景。

### 搜索不到文档

确认文档扫描通过，并等待后台索引完成。

### 导入部分失败

下载结果中的错误清单，按行修复后重新导入失败行。不要重复导入已成功的项目编号。

### 导出一直排队

联系管理员检查 Celery worker、Redis 和 storage。

### 英文界面仍有部分中文

当前已覆盖核心导航、登录、通用按钮、状态和错误提示；业务数据本身、历史配置名称和部分页面专有文案可能仍以中文展示。
