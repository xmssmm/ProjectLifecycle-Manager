# 使用手册

本文面向业务用户，说明系统的核心操作流程。系统用于采购类项目的立项、审核、子项目管理、环节推进、资料归档、任务协作、付款记录、报表和通知。

## 1. 角色说明

| 角色 | 主要能力 |
| --- | --- |
| admin | 用户、部门、转交、审计、全局查看和兜底审核 |
| dept_manager | 主项目审核、子项目审核、结项/终止、部门视角统计 |
| proj_leader | 创建和管理子项目、推进环节、分配任务、上传资料 |
| proj_member | 查看参与项目、执行任务、上传相关资料 |
| finance_manager | 登记付款、查看付款报表和财务仪表盘 |

## 2. 登录与个人设置

1. 打开系统地址。
2. 输入用户名和密码登录，或点击“企业账号”使用 SSO 登录。
3. 首次登录或被管理员重置密码后，按页面提示修改密码。
4. 进入 `我的` 或个人信息页，可维护邮箱、通知偏好和企业账号绑定。

如果 admin 已把账号设置为“仅 SSO”，本地密码登录会被拒绝，需要使用企业账号登录。首次使用 SSO 前，本地账号必须已存在；如果企业账号邮箱与本地账号邮箱一致，按页面提示完成绑定即可。

通知偏好支持：

- 全部通知。
- 仅与我直接相关。
- 自定义场景开关。
- 实时通知或每日摘要。每日摘要会把前一天的摘要模式通知按场景合并成一条。
- 通知通道开关：站内、邮件、企业微信、钉钉。站内通知默认保留，外部通道需要运维先完成配置。

## 3. 工作台与仪表盘

登录后可进入仪表盘。系统会按角色展示不同指标：

- 管理员查看全系统项目、用户、超预算和错误率。
- 部门经理查看项目状态分布、部门项目数和超预算项目。
- 财务查看付款总额、预算使用和付款排行。
- 项目负责人查看负责项目、到期任务、待推进环节。
- 项目成员查看我的待办和参与项目动态。

主项目详情页提供进度漏斗，可点击环节查看对应子项目列表。

## 4. 主项目流程

1. dept_manager 创建主项目草稿。
2. 创建人提交审核。
3. 非创建人的 dept_manager 或 admin 审核。
4. 审核通过后，可创建子项目。
5. 所有子项目完成后，dept_manager 可结项主项目。

如果审核不通过，按驳回意见修改后重新提交。

## 5. 子项目与环节

1. proj_leader 创建子项目并提交审核。
2. dept_manager 或 admin 审核通过。
3. 系统生成 6 个固定环节。
4. 项目负责人按环节上传资料、维护验收步骤、分配任务。
5. 满足必传文档和业务规则后推进到下一环节。

部分敏感操作会写入审计日志。

## 6. 文档管理与预览

文档支持上传、下载、版本记录和预览。

- PDF 使用内置 PDF 预览。
- Word、Excel、PowerPoint 使用 Office 预览，系统会转换成 PDF 副本展示。
- 禁止上传可执行文件或包含风险内容的压缩包。
- 单文件大小默认上限为 50MB。
- 新上传文档会先显示“扫描中”，通过后显示“已通过”；若识别为风险文件，会显示“已隔离”且不能下载或预览。

如果 Office 预览失败，先下载原文件确认文件本身可打开，再联系管理员查看后端日志。

## 7. 任务协作

项目负责人可以给一个或多个成员分配任务，设置计划完成日期。

任务执行人可以：

- 查看我的任务。
- 更新任务状态。
- 完成自己负责的任务。

移动端支持“我的任务”快捷完成，通常两步内完成：点击完成并确认。

系统每日 09:00 扫描到期、逾期和逾期 7 天以上任务，并发送通知。

## 8. 付款与预算

finance_manager 可在子项目下登记付款。

系统会：

- 维护子项目累计付款金额。
- 在付款超过预算时要求二次确认。
- 将付款和超预算事件通知相关用户。
- 支持付款流水和部门汇总报表。

发生错误付款时，可登记红冲记录，系统会重新计算累计付款。

## 9. 撤销与转交

### 9.1 环节撤销

项目负责人可对已完成环节发起撤销申请。审核通过后，系统会回滚后续环节并软删除相关文档。

### 9.2 负责人转交

admin 可查看某负责人名下进行中的子项目，并执行单个或批量转交。已关闭项目不会进入待转交列表。

proj_leader 也可以从“转交”入口发起自助转交申请，将自己负责的进行中子项目移交给新的负责人。提交后需审核；审核通过后，新负责人接管项目，相关人员会收到通知。

## 10. 报表导出

报表入口支持：

- 项目清单。
- 付款流水。
- 部门项目汇总。
- 月度统计。

小报表可快速生成，大报表进入后台任务。生成后可在 7 天内下载，过期后系统会自动清理。

## 11. 开放 API 与 Webhook 管理

本节面向 admin 和外部系统对接人员。

### 11.1 API Key

进入“API Key 管理”页可以：

1. 创建 API Key，选择权限范围：项目只读、付款只读、文档只读。
2. 设置过期时间；不填则长期有效，仍可随时吊销。
3. 创建后立即保存 token，页面之后只展示 key 前缀，不再展示完整 token。
4. 对接系统在请求头中传入 `X-API-Key: <token>`。

开放只读接口包括：

- `/api/external/v1/projects`
- `/api/external/v1/payments`
- `/api/external/v1/documents`

如果外部系统返回 401/403/429，请联系 admin 检查 token、权限、吊销状态、过期时间和限流。

### 11.2 Webhook

进入“Webhook 管理”页可以：

1. 创建 Webhook，填写名称、URL、签名密钥和订阅事件。
2. 启用或停用某个 Webhook。
3. 查看死信队列。
4. 对死信投递执行重放。

当前事件包括：项目状态变更、付款发生、环节推进、撤销审核完成。对接系统需要验证 `X-Signature`，并保证 2xx 响应代表已成功接收。

## 12. 移动端使用

系统在手机宽度下可浏览主要页面。移动端推荐用于：

- 查看仪表盘和项目状态。
- 查看任务详情。
- 快速完成我的任务。
- 查看通知。
- 预览 PDF/Office 文档。

审核、付款和环节推进等复杂操作建议在 PC 端完成。

## 13. 常见问题

### 看不到某个项目

先确认自己的角色和项目关系。proj_leader/proj_member 只能查看自己负责或参与的项目；需要扩大权限时联系管理员。

### 通知没有实时出现

进入个人设置检查是否选择了每日摘要，或该场景是否被关闭。每日摘要会在次日 09:00 合并发送。

### 报表一直生成中

联系管理员检查 Celery worker 是否运行，以及 `storage/` 是否可写。

### 文档无法预览

PDF 和 Office 预览使用不同接口。非支持格式只能下载；Office 转换失败时联系管理员按 `docs/office-preview.md` 排查。

### 企业账号登录失败

先确认是否已绑定企业账号，或本地账号邮箱是否与企业账号一致。仍失败时联系管理员检查 SSO 配置和回调日志。

### API Key 调用失败

确认外部系统使用的是完整 token 而不是页面展示的 key 前缀；再确认权限范围是否覆盖目标接口，以及 key 是否过期或被吊销。

### Webhook 没有收到推送

先确认 Webhook 处于启用状态、订阅了对应事件，且接收方返回 2xx。若连续失败，可在死信队列中查看错误并手动重放。
