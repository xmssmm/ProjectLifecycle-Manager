# Phase 2 开放问题决策

来源：`docs/ROADMAP.md` Phase 2。

用户已授权后续由 Agent 自行确认并继续执行，因此本文件记录默认决策，作为 Phase 2 实施依据。

## OQ-11：Office 预览方案

决策：优先采用 LibreOffice 转 PDF。

理由：

- 部署和 license 风险低于 OnlyOffice。
- 与 MVP 已有 PDF 预览能力衔接自然。
- 先满足在线预览需求，不引入在线编辑和协同编辑复杂度。

后续如果业务明确要求原格式编辑，再单独评估 OnlyOffice。

## OQ-12：报表是否需要电子签章

决策：Phase 2 不做电子签章。

理由：

- 当前 roadmap 的核心痛点是统计导出，不是正式用印。
- 电子签章涉及证书、印章权限、审计和合规流程，适合独立立项。
- Phase 2 报表先提供 Excel/PDF，保留水印/签章扩展点。

## OQ-13：仪表盘缓存是否可接受

决策：仪表盘数据缓存 5 分钟可接受。

理由：

- Roadmap 明确要求单个仪表盘接口响应时间 ≤ 500ms。
- 仪表盘用于管理观察，不作为交易一致性依据。
- 缓存 key 必须包含角色和用户身份，避免权限串数据。
